# 📌 Project Overview

This project is an Ajio Clone eCommerce web application developed to demonstrate modern web application development practices.

The application includes product display, user interaction, and registration workflow using HTML, JavaScript, and Node.js technologies.

The project focuses on frontend development, JavaScript functionality, and building a complete shopping website experience.

# 🚀 Local Installation

Clone Repository

```bash
git clone https://github.com/varaprasad-h/ajio-prasad.git

cd ajio-prasad
```

---

Install Dependencies

```bash
npm install
```

---

Run Application

```bash
npm start
```
